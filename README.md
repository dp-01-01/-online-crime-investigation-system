# Online Crime Investigation System

## Project Description

The Online Crime Investigation System is a web-based application
designed to help investigators manage crime cases, complaints,
victims, suspects, evidence and investigation activities.

## Objectives

- Manage crime cases
- Manage victims and suspects
- Store investigation information
- Manage evidence records
- Track investigation status
- Search and filter cases
- Generate investigation reports

## Technologies

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Git
- GitHub
